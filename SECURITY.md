# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **Report a vulnerability**
button under the repository's *Security* tab. Do not open a public issue for
anything security-sensitive.

Include what you found, how to reproduce it, and its impact. You will receive
an acknowledgement and updates as the report is triaged and fixed.

## Scope

The server, CLI, dashboard, container image, and CI pipelines in this
repository are in scope. Issues in third-party dependencies should also be
reported here so they can be triaged against what the code actually reaches.
